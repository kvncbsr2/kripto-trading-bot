# KRIPTO AGENT — API Documentation

FastAPI backend with OpenAPI / Swagger UI available at:
`http://localhost:8000/docs`

Interactive Visual Dashboard:
`http://localhost:8000/dashboard`

---

## Endpoint Catalog

### System & Health
* `GET /health`: Liveness probe, confirms `LIVE_TRADING=false` and `PAPER_TRADING=true`.
* `GET /health/ready`: Readiness probe, checks database connection.
* `GET /system/status`: Subsystem status (Market Data, Database, Risk Engine, Paper Broker, etc.).
* `GET /dashboard`: Interactive web dashboard HTML application.

### Market Data
* `GET /market/status`: Exchange connectivity and supported symbol pairs.
* `GET /market/candles?symbol=BTC/USDT&timeframe=15m&limit=100`: Returns normalized OHLCV candles.

### Signals & Strategies
* `GET /signals`: Historical signals generated by strategy engine.
* `GET /signals/latest`: Most recent signal with score and opportunity rating.
* `GET /strategies`: Active strategies registry.
* `GET /strategies/performance`: PnL and win-rate breakdown per strategy.

### Portfolio & Positions
* `GET /portfolio`: Balance, equity, unrealized/realized PnL, drawdown.
* `GET /portfolio/history`: Historical portfolio snapshots.
* `GET /positions?status=OPEN`: Active or historical positions.
* `GET /orders`: Recent orders.
* `GET /trades`: Executed simulated fills with fees and slippage.

### Risk & Compliance
* `GET /risk/status`: Current risk parameters, daily loss limit, circuit breaker state.
* `GET /risk/events`: Audit log of circuit breaker and risk lock events.

### Performance & Reports
* `GET /performance/daily`: Day-level metrics and target hit benchmarks.
* `GET /performance/weekly`: 7-day validation report with Monte Carlo output.
* `GET /backtests`: Historical backtest runs.
* `GET /backtests/{id}`: Detailed backtest metrics by ID.
